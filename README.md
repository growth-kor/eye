# 👁️ The Watchful Eye

> **"I'M WATCHING YOU"**

대표님을 전담 수호하며 시선과 마우스 커서를 실시간으로 감시 및 추적하는 인터랙티브 아스키 아트 웹 애플리케이션입니다.

- 🖥️ **Live Web Demo**: [https://growth-kor.github.io/eye/](https://growth-kor.github.io/eye/)
- ⌨️ **Controls**: 
  -  키 (한글 자판 'ㄹ' 상태 포함): 전체 화면 (Fullscreen) 토글
  - : 눈동자가 커서를 360도 실시간 추적
  - : 눈동자가 24시간 화면을 튕겨 다니는 'I'M WATCHING YOU' 문구 자동 응시
